# 길동무

같은 길을 지나는 운전자끼리 목소리 한마디를 남기고 듣는, **길 위의 방명록**입니다.
현대자동차그룹 차량용 앱 개발 공모전(Pleos Connect) 출품작입니다.

- 주행 중에는 소리로, 정차 중에는 화면으로 씁니다.
- 운전자에게 묻는 것은 "앞에 길동무가 있어요. 들어 볼까요?" 한 번뿐입니다.

## APK 위치

[`apk/고낭희_길동무_release.apk`](apk/고낭희_길동무_release.apk)

- 서명된 release APK입니다. 배포한 서버 주소가 들어 있어 설치하면 바로 서버에 연결됩니다.
- 패키지 `com.gildongmu.app`, 버전 0.1.0

## 1차에서 되는 것

| 기능 | 내용 |
|---|---|
| 듣기 | 같은 방향 앞쪽에 다른 운전자가 남긴 한마디가 있으면, 닿기 약 10초 전에 차 안 음성(Pleos TTS)으로 한 번 묻습니다. 대답하면 그 자리(50m 안)에 모인 한마디를 차례로 들려주고, 하나가 끝날 때마다 4초 동안 "고마워"를 기다립니다 |
| 대답 | 말(Pleos STT): "응"(듣기), "넘겨"(지나가기), "고마워"(고마워요), "그만"(멈춤). 핸들 재생 버튼과 화면 버튼도 됩니다 |
| 남기기 | "나도 한마디 남기기" 버튼으로 최대 15초 녹음합니다. 녹음을 시작한 위치·진행 방향·와이퍼·전조등 상태를 함께 저장합니다 |
| 검수 | 서버가 음성을 글자로 바꾸고(Google Speech-to-Text), 비속어 사전과 Claude 판정을 거쳐 공개합니다. 검수 중에는 씨앗, 공개되면 새싹입니다 |
| 고마워요 | 들은 한마디에 고마워요를 보냅니다. 5개를 받으면 꽃이 핍니다 |
| 운전 안전 | 듣는 동안 음악은 잠시 멈추고, 내비 안내 음성이 나오면 한마디도 멈췄다가 이어서 재생합니다. 주행 중에는 큰 버튼만 보여 줍니다 |
| 화면 밖 동작 | 앱 창을 닫거나 내비를 앞에 띄워도 계속 동작합니다 |
| 정차 중 | 내 발자취(남긴 한마디, 검수 결과, 들은 사람·고마워요 수), 설정, 내 길동무(닉네임·모습, 나만 보기) |

자기가 남긴 한마디는 자기에게 들리지 않습니다. 다른 운전자의 한마디만 안내합니다.

## 테스트 환경

| 항목 | 값 |
|---|---|
| 에뮬레이터 | Pleos Connect v2.1.0 (Android 14, API 34), 운전자 사용자(user 10) |
| 확인한 컴퓨터 | Apple Silicon Mac. 에뮬레이터는 `-feature -Vulkan`을 붙여 켜야 부팅 직후 멈추지 않았습니다 |
| 앱 | Kotlin, minSdk 28, targetSdk 34, compileSdk 37 (AGP 9.5, Gradle 9.6) |
| Pleos SDK | Vehicle 2.3.2, NaviHelper 3.0.5, TextToSpeech 3.3.1, SpeechToText 3.3.1 (Playground 저장소, 로그인 불필요) |
| 서버 | Go 1.27, Google Cloud Run(서울) + PostgreSQL |
| 검수 | Google Speech-to-Text(ko-KR) → 비속어 사전 → Claude API |

```bash
~/Library/Android/sdk/emulator/emulator -avd Pleos_Connect_v2.1.0 -no-snapshot-load -feature -Vulkan
```

## 설치와 실행

### 1. 설치

```bash
adb install -r "apk/고낭희_길동무_release.apk"
```

전에 직접 빌드한 debug 앱이 깔려 있으면 서명이 달라 설치가 실패합니다. 이때는 `adb uninstall com.gildongmu.app` 뒤에 다시 설치합니다.

### 2. 첫 실행

1. 운전자 화면의 앱 목록에서 **길동무**를 엽니다.
2. 위치, 마이크, 알림 권한을 허용합니다.
3. 길 위에서 불릴 이름(닉네임)과 내 길동무 모습을 정하고 **이 이름으로 시작할게요**를 누릅니다.

### 3. 주행 흉내 내기

- **기어:** Pleos 에뮬레이터의 Virtual Console에서 기어를 **D**로 바꾸면 주행 중 화면이 됩니다. **P**로 바꾸면 정차 중 화면(내 발자취·설정)이 됩니다.
- **위치와 속도:** 아래 시험 경로 스크립트를 쓰거나, 1초마다 위치를 조금씩 옮깁니다. 앱은 움직인 방향으로 진행 방향을 계산합니다.

```bash
# geo fix <경도> <위도> <고도> <위성 수> <속도(노트)>: 21.6노트 ≈ 시속 40km, 위도 0.0001 ≈ 11m
adb emu geo fix 126.9772 37.5650 30 8 21.6
adb emu geo fix 126.9772 37.5651 30 8 21.6
adb emu geo fix 126.9772 37.5652 30 8 21.6
```

### 4. 시험 경로에서 바로 들어 보기

배포 서버의 시험 경로(서울시청 앞 → 광화문, 경도 126.9772)에 시연용 한마디를 미리 심어 두었습니다. 목소리는 Mac 합성 목소리입니다.

| 위치 | 방향 | 한마디 |
|---|---|---|
| 광화문 광장 앞 (위도 37.5728~37.5732) | 북쪽 | 3개. 첫 한마디는 고마워요 4개를 미리 받아 둠 |
| 서울시청과 광화문 사이 (위도 37.5690) | 남쪽 | 1개 |

1. Virtual Console에서 기어를 **D**로 바꿉니다.
2. 시험 경로를 북쪽으로 달립니다(2분 남짓, adb 필요).

   ```bash
   tools/demo/drive.sh north
   ```

3. 광장 약 100m 전에 "앞에 길동무 3명이 있어요. 들어 볼까요?"라고 묻습니다. "응"이라고 말하거나 **들어 볼게요** 또는 핸들 재생 버튼을 누릅니다.
4. 3개가 차례로 나옵니다. 첫 한마디가 끝난 뒤 4초 안에 "고마워"라고 말하거나 **고마워요**를 누르면 고마워요 5개가 되어 꽃이 핍니다. 먼저 누른 사람이 있으면 이미 꽃입니다.
5. 남쪽 방향 한마디는 북쪽으로 갈 때 나오지 않습니다. `tools/demo/drive.sh south`로 거꾸로 달리면 그 1개만 나옵니다(같은 방향 필터).

- 안내는 5분에 한 번만 묻습니다. 끝까지 듣거나 넘긴 한마디는 같은 기기에서 다시 나오지 않습니다.
- 다시 시험하려면 앱 데이터를 지웁니다. 새 기기로 보고 처음부터 다시 나옵니다(권한과 닉네임은 다시 정함).

```bash
adb shell pm clear --user 10 com.gildongmu.app
```

### 5. 직접 남기고 듣기

- **남기기:** **나도 한마디 남기기**를 누르고 말합니다. 에뮬레이터 마이크는 기본으로 무음이라 Mac 마이크를 연결해야 합니다(`adb emu avd hostmicon`). 무음이면 검수에서 말소리가 없어 공개되지 않습니다.
- **듣기:** 같은 방향 앞쪽에 다른 운전자의 한마디가 있으면 "앞에 길동무가 있어요. 들어 볼까요?"라고 묻습니다. "응"이라고 말하거나 **들어 볼게요**를 누릅니다. 핸들 재생 버튼은 아래 명령으로 흉내 낼 수 있습니다.

```bash
adb shell input keyevent KEYCODE_MEDIA_PLAY
```

- **혼자서 시험하기:** 자기 한마디는 들리지 않으므로, 한마디를 남기고 몇 초 뒤 앱 데이터를 지우면(위 `pm clear`) 다른 운전자가 됩니다. 그다음 같은 길을 같은 방향으로 다시 지나면 안내가 나옵니다.

## 소스에서 빌드

```bash
# JDK는 Android Studio에 들어 있는 것을 씁니다
export JAVA_HOME="/Applications/Android Studio.app/Contents/jbr/Contents/Home"

# debug 앱: 에뮬레이터에서 내 컴퓨터의 로컬 서버(http://10.0.2.2:8080/v1)에 붙습니다
./gradlew :app:assembleDebug

# 로컬 서버: 검수 없이 올린 한마디를 바로 공개합니다(개발 전용)
cd server && DEV_AUTO_APPROVE=true go run ./cmd/server
```

release APK는 서버 주소(`-Pgildongmu.serverUrl=https://…/v1`)와 저장소 밖의 서명 키가 있어야 만들어집니다. 서버 배포와 release 빌드 순서는 [docs/deploy.md](docs/deploy.md)를 따릅니다.

## 폴더 구조

```
app/      차량 앱(Kotlin): 위치·차량 신호, 안내·재생, 녹음·업로드, 화면
server/   서버(Go): API, 검수(Google STT·비속어 사전·Claude), DB(GORM)
docs/     api.md(앱과 서버의 약속), deploy.md(배포·release 빌드)
apk/      제출용 release APK
tools/demo/  시험 경로 달리기(drive.sh), 시연용 한마디 심기·지우기(seed.py·unseed.py, Mac 전용)
```
